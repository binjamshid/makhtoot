# Changelog

## Unreleased

- Opened all implemented iPhone and iPad features for free, including font and image import, all export formats and resolutions the app supports, and optional iCloud project sync. The app no longer offers purchases, trials or referral rewards. Earlier App Store subscriptions are managed through Apple.
- Applied the same free-access policy to the Android scaffold and removed its paywall and trial backup configuration. The Android editor is still in development.
- Added a contributor entry point for the iOS editor and Android port, including Arabic first-use instructions, build paths, a document-format reference and a typography reporting guide.
- Documented the Binjamshid Public Fork License, asset licensing, community review process and private reporting channels.
- Added the original notices for all 45 Android font families, made PDF export samples local-only, and made iCloud project sync require an explicit, saved opt-in.

This file tracks changes intended for a public source edition. App Store and TestFlight build numbers have a separate release history.
