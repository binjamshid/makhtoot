# Privacy and services

Makhtoot keeps projects on the device and has no Makhtoot account or application backend. The bilingual privacy policy covers iOS and iPadOS. This guide describes the behavior and configuration visible in the repository, including the Android port under development. [Privacy policy](legal/privacy.html)

## iPhone and iPad

**Local projects.** The app stores `.makhtoot` packages in its managed project library. A package contains the project manifest, scene and any included assets or thumbnail. Editing, saving, using bundled fonts and exporting use local files. When you share an export or copy a project out through Files, you choose where that copy goes. [Project library implementation](../Makhtoot/AppShell/Persistence/MKPersistenceProjectLibrary.swift), [editor sharing](../Makhtoot/AppShell/Scenes/Editor/EditorScene.swift)

**Project sync.** Project sync defaults to off. The app keeps the user's choice on the device across relaunches. When you enable sync in Settings and iCloud is available, the engine uses the private database in your iCloud account for project titles, folder identifiers, manifests, scenes, thumbnails, assets, and change metadata. Turning sync off stops new sync activity and requests cancellation of in-progress transfers. Previously synced copies may remain in iCloud. [CloudKit schema](../MakhtootKit/Sources/MKSync/Docs/CloudKitSchema.md), [app startup](../Makhtoot/AppShell/AppContainer.swift), [sync controller](../MakhtootKit/Sources/MKSync/Engine/MKSyncEngineController.swift), [sync settings](../Makhtoot/AppShell/Scenes/Settings/SyncSettingsView.swift), [privacy policy](legal/privacy.html)

**Font-usage analytics.** Collection defaults to off. Settings → Privacy records consent locally. With consent, the analytics service can count font use on device and upload batches to the app's CloudKit public database. The app-supplied payload consists of a random batch ID, ISO week, major.minor app version, and pairs of font ID and count range. Project contents, font files, and persistent user or device identifiers are outside the payload. Revoking consent disables subsequent collection and clears local counters when the revocation saves. The startup and consent paths are wired in this checkout. The editor has no call to record font use here. Any editor integration should restrict recording to bundled fonts, as described in the policy. [Consent manager](../MakhtootKit/Sources/MKAnalytics/Consent/MKConsentManager.swift), [upload payload](../MakhtootKit/Sources/MKAnalytics/Upload/MKFontUsageBatch.swift), [app startup](../Makhtoot/AppShell/AppContainer.swift)

**Earlier subscriptions and trial records.** All implemented features are free. The app no longer uses StoreKit for feature access or reads, writes or syncs trial timing. Earlier versions could leave trial records in Keychain and iCloud key-value storage. Apple handles earlier App Store subscriptions through your Apple Account. [Manage Apple subscriptions](https://apps.apple.com/account/subscriptions) · [App terms](legal/terms.html)

**Fonts.** The checked-in configuration uses bundled delivery and supports local font import. Fonts remain subject to their license terms. A hosted mode exists in source for downloading fonts over HTTPS, with an intentionally invalid placeholder URL. [Font delivery configuration](../MakhtootKit/Sources/MKFonts/MKPremiumDelivery.swift)

## Android

The Android scaffold follows the free-access policy and has no launcher activity in its application manifest. Project sync through Google Drive's `appDataFolder` is planned for transfers between Android devices. The sync and analytics modules are still scaffolded. [Android manifest](../android/app/src/main/AndroidManifest.xml) · [Sync controller](../android/mk-sync/src/main/kotlin/net/binjamshid/makhtoot/mk/sync/engine/MkSyncEngineController.kt) · [Analytics service](../android/mk-analytics/src/main/kotlin/net/binjamshid/makhtoot/mk/analytics/service/MkAnalyticsService.kt)

The Android manifest disables automatic backup. The Android 12 and later data extraction rules exclude app data from device-to-device transfer. [Android manifest](../android/app/src/main/AndroidManifest.xml) · [Data extraction rules](../android/app/src/main/res/xml/data_extraction_rules.xml)

## Fork configuration

Use your own signing identity, bundle or application ID, support address and policy URLs for an independently distributed fork. Keep credentials, signing files and private configuration out of publicly shared source. Use placeholders where readers need configuration examples. [iOS entitlements](../Makhtoot/Config/Makhtoot.entitlements), [Android app configuration](../android/app/build.gradle.kts), [iOS legal links](../MakhtootKit/Sources/MKAnalytics/MKLegalLinks.swift), [license](../LICENSE)

| Service | What the fork needs |
|---|---|
| iOS project sync | An iCloud container provisioned for the fork. Set the container consistently in `Makhtoot.entitlements` and `MKSyncSchema.swift`, then configure the private-database schema. To omit sync, skip the CloudKit controller bootstrap and omit its capability unless another feature uses it. [Sync schema](../MakhtootKit/Sources/MKSync/Schema/MKSyncSchema.swift), [app startup](../Makhtoot/AppShell/AppContainer.swift) |
| iOS analytics | A CloudKit public-database schema in the fork's default container, with permissions appropriate for the upload and configuration records. To omit analytics, keep recording and upload disabled and use an inert database implementation. [Analytics schema](../MakhtootKit/Sources/MKAnalytics/Docs/AnalyticsSchema.md), [database interface](../MakhtootKit/Sources/MKAnalytics/Upload/MKCloudKitPublicDatabase.swift) |
| Hosted fonts | Keep bundled delivery for offline use. If you enable hosted delivery, supply a catalog and a static HTTPS host for font files cleared for that distribution. [Font delivery configuration](../MakhtootKit/Sources/MKFonts/MKPremiumDelivery.swift) |
| Android services | A working Drive sync integration would use the fork's Google Cloud project and OAuth configuration for its application and signing identities. Keep analytics transport inert until a separately configured and disclosed service is available. [Android decisions](../FOUNDATION.md) · [Android app configuration](../android/app/build.gradle.kts) |

The iOS analytics tests use a spy database to exercise consent, upload gating and payload fields without a CloudKit account. The sync tests exercise the saved choice, entitlement gate, a delayed account response after opt-out, and conflict decisions using local fixtures. For device checks, use the fork's development configuration and disposable projects. Verify sync and analytics over launch, opt-in and opt-out, including relaunch after disabling sync, before describing the fork's behavior in its privacy policy. [Build instructions](BUILD.md), [analytics tests](../MakhtootKit/Tests/MKAnalyticsTests), [sync tests](../MakhtootKit/Tests/MKSyncTests)
