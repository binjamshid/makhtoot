# Security

## Report a vulnerability privately

Email [support@binjamshid.com](mailto:support@binjamshid.com) with the subject **Makhtoot security report**. This is the contact listed in the app and its privacy policy. Keep vulnerability details out of public issues, pull requests and discussions while coordinating a fix. [In-app contact](MakhtootKit/Sources/MKAnalytics/MKLegalLinks.swift), [privacy policy](docs/legal/privacy.html)

Reports can cover the current repository source and the latest official app build where one is available. If your finding affects an older build, include its version and whether you have observed the same issue in a newer one.

Include the platform, OS version, app version and build number or Git commit, the affected feature, what happened, and the likely impact. Use a small synthetic project or sanitized evidence where possible. Leave out real project content, personal data, credentials and access links. For an issue affecting a fork, contact its maintainer privately and contact Makhtoot privately if the upstream code is also affected.

## Publishing a security fix made in a fork

Section 4 of the [Binjamshid Public Fork License](LICENSE) applies to covered modifications. Its ordinary source publication deadline is 30 calendar days after making the change or before first distributing the changed version or allowing others to use it as a service, whichever comes first.

If publishing a fix would disclose an unremediated vulnerability, section 4 allows a delay when necessary for coordinated remediation. Promptly notify the affected maintainer privately. The delay ends at the first public disclosure of the vulnerability or 90 calendar days after making the fix, whichever comes first. The ordinary deadline still applies if it would expire later. During the delay, you may share the fix privately with affected maintainers or operators to remediate the vulnerability. Unrelated changes follow the ordinary deadline. Keep secrets, personal data and private configuration values out of the published source.
